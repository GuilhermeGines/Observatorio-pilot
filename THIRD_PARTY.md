# Componentes de terceiros

O código e dados de bibliotecas mantêm suas licenças próprias. Versões exatas do frontend estão em frontend/package-lock.json; do ambiente Python, em requirements-lock.txt.

- React / React DOM — MIT.
- Vite / TypeScript — MIT / Apache-2.0.
- d3-geo — ISC; topojson-client — ISC.
- world-atlas — ISC, dados base Natural Earth em domínio público. O globo usa countries-110m.json incluído no bundle, sem conexão a mapas externos. Fronteiras são ilustrativas e não representam posição diplomática.
- lucide-react — ISC.
- FastAPI — MIT; Uvicorn — BSD-3-Clause; HTTPX — BSD-3-Clause.
- Beautiful Soup — MIT; feedparser — BSD-2-Clause; trafilatura — Apache-2.0.
- OpenAI Python — Apache-2.0; keyring — MIT; pypdf — BSD-3-Clause.

Notícias, documentos, marcas e nomes de fontes pertencem aos respectivos titulares. O projeto não concede direito de redistribuir seu conteúdo; o código compartilhável não inclui o acervo pessoal coletado.
